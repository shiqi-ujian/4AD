# 通用跑团辅助工具

> ⚠️ **定位说明**：`2_工具/` 下的地图工具已从「四战黑专属」转为**通用 TRPG / 跑团地图工具**，不局限于任何特定规则或世界观。界面标题、地形、王国/定居点命名均采用中性的奇幻通用内容，可配合任何系统使用。

## 地图工具

| 文件 | 说明 |
|------|------|
| `hexmap/` | 六角格沙盒地图工具（通用，模块化源码，测试入口 index.html） |
| `hexmap.dist.html` | 六角格沙盒地图工具（发布版，由 build.js 打包生成，勿手改） |
| `citymap.html` | 城市地图生成器（通用） |
| `squaremap.html` | 方格地图工具（通用） |
| `room_annotator.html` | 房间目录编辑器 |

## 开发辅助

| 文件 | 说明 |
|------|------|
| `brace_check.js` | hexmap 大括号平衡检查器（调试用+组合为单文件测试可用性） |
