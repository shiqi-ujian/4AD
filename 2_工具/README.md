# 通用跑团辅助工具

> ⚠️ **定位说明**：`2_工具/` 下的地图工具已从「四战黑专属」转为**通用 TRPG / 跑团地图工具**，不局限于任何特定规则或世界观。界面标题、地形、王国/定居点命名均采用中性的奇幻通用内容，可配合任何系统使用。

> 🔒 **开发重心**：目前地图工具的**新开发只针对 `hexmap/` 与 `combatmap/`**（两个同级主力工具）。`citymap.html` / `squaremap.html` 已霜冻（不再主动改动）。如旧工具里有值得保留的能力，请迁移到上述主力工具，而非继续在旧工具里加。

> 🌐 **在线入口**：GitHub Pages 自动构建发布——仓库根目录 `web/index.html` 是入口首页，线上地址为 `https://shiqi-ujian.github.io/4AD/`。两个 dist 都支持带 `#m=` 参数的地图分享链接，打开即自动加载。
