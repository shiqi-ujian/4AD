# 通用六角格沙盒地图 — 更新日志

## [x.y.z] — 开发中 (Unreleased)

### ✨ 新增
- **探索迷雾（Fog of War）**：工具栏「🌫️ 探索迷雾」勾选即隐藏未探索区；新增「🔦 探索(F)」工具，点击揭示该格及周边一圈（ring 1），按住拖拽连续揭示；`👁️ 全部揭示` / `🌑 重设迷雾` 一键操作。
- 迷雾状态随 **保存(.hexmap)** 与 **分享/导入** 一并持久化（`fog` 字段）；旧存档无该字段时默认关闭，向后兼容。
- 统计面板：迷雾开启时额外显示「已揭示/未揭示」格数与探索进度百分比。

### 🔧 变更
- 开发重心转向通用 TRPG：仅保留 hexmap 为活跃工具，citymap / squaremap 霜冻。
- 界面标题/页脚/启动日志去除「四战黑」字样，改为中性通用命名（通用六角格地图工具 v1.0）。
