# 通用六角格沙盒地图 — 更新日志

> 记录目标随 `hexmap/` 源码一起提交。每次有实质改动后，在此**倒序**顶格追加入口（最新在最上）。格式见文末「追加模板」。

## [x.y.z] — 开发中 (Unreleased)

### 🌊 河流可视化重构
- **河流不再画在整条六边形共享边**，改为**流经格心的贝塞尔中心线**：两格中心 → 共享边中点 → 相邻格中心，带轻微弧形自然弯曲。
- **溪流 / 河宽度视觉区分**（溪 3.2px、河 5px，双层配色 + 深色描边），并新增**河交汇圆角结点**（≥2 条河在格心相连时自动画圆点）。
- **道路跨河画桥**：道路跨越河流边时，手绘模式下显示桥面 + 桥栏，不再整段直盖河道。
- **渲染层级修正**：河流仍压在道路/覆盖层之下，但 overlay 的纸张阴影不再涂抹在河道上。
- **导出统一**：全图 PNG / 视野导出与画布同用 `drawRiverPath` 贝塞尔渲染，所见即所得。

### 🐛 修复
- **生成河流的汇水方向 bug**：`flowTo` 平局分支有残影赋值与错误重复 `best = dn.elev`，重构为“严格更低 + 字典序 tie-break”的纯遍历，消除随机/断开流域。
- **河流宽度语义修正**：宽度改由**上游累积量**决定（源头细、下游粗，链式河宽连续），不再取下流格面积导致整片偏粗。
- **区域边界断头河**：生成区域边缘的汇水盆地若没有更低邻居，会沿边界向外排水，不再戛然而止。
- **旧存档单向河流归一化**：加载/导入/初始化时 `normalizeAllRivers()` 幂等清理，左右两侧宽度取 max、去重，修复幽灵/重复边。
- 统计面板河流计数改用与渲染一致的 `edgeKey` 去重。

### ✏️ 交互
- 右键有河流的格子新增「🌊 河流宽度（此格）：河 2 / 溪 1」菜单，点击在 1/2 间切换（该格所有相邻河流边一起切换）。

## [x.y.z] — 开发中 (Unreleased)

### ✨ 新增
- **🎨 手绘质感美术开关**：新增「✏️ 手绘质感」选项（显示开关区，默认开启，可切回原纯色块）。
  - 画布：平原 / 森林 / 丘陵 / 山地 / 水域 / 沙漠 / 沼泽等填充加入 **纸面噪点、水波纹、草痕、排线、点状纹理**；格线改为暖色手绘墨线。
  - 道路：双色手绘泥土路径；河流：手绘蓝色双线描边。
  - 侧栏 / 信息面板同步暖色牛皮纸壳风格；偏好写入 localStorage.hexmap_artStyle。
  - PNG 导出 / 视野导出与画布渲染保持一致。

## [x.y.z] — 开发中 (Unreleased)

### ✨ 新增
- **遭遇表（Encounter Tables）**：工具栏新增「⚔️ 遭遇」按钮，按**当前选中格地形**挑选对应遭遇表（未选或陌生地形回退到「全图」兜底表）。
  - 每张表 10 条 d10 / 20 条 d20 可切换，支持「🎲 整体重掷」和「单行重掷」。
  - 表内条目**可编辑**，改动自动持久化到 `localStorage`（`encounter_tables`），下次打开仍在。
  - 当前掷得结果可「📌 存入选中格」——写为该格的 `hazard` 类型标注（遭遇文本），随地图保存/分享保留。
  - 内置 12 张中性奇幻通用表（全图/平原/森林/丘陵/山地/水域/沙漠/沼泽/雪地/废墟/荒土/死灵），非 4AD 专属。
- **探索迷雾（Fog of War）**：工具栏「🌫️ 探索迷雾」勾选即隐藏未探索区；新增「🔦 探索(F)」工具，点击揭示该格及周边一圈（ring 1），按住拖拽连续揭示；`👁️ 全部揭示` / `🌑 重设迷雾` 一键操作。
- 迷雾状态随 **保存(.hexmap)** 与 **分享/导入** 一并持久化（`fog` 字段）；旧存档无该字段时默认关闭，向后兼容。
- 统计面板：迷雾开启时额外显示「已揭示/未揭示」格数与探索进度百分比。

### 🔧 变更
- 开发重心转向通用 TRPG：仅保留 hexmap 为活跃工具，citymap / squaremap 霜冻。
- 界面标题/页脚/启动日志去除「四战黑」字样，改为中性通用命名（通用六角格地图工具 v1.0）。
