# combatmap UI 设计审计与改造方案

> 本文档对照枭熊（Owlbear Rodeo）与 FVTT，审计 combatmap v0.93 的**界面信息架构**，
> 找出「不好用」的具体成因，并给出**分阶段**、可独立上线的改造路线。
> 本文档为**设计/规划文档**，不替代 `CHANGELOG.md`（记录已落地改动）；落地时才动代码与 `COMBATMAP_VERSION`。
>
> 撰写：2026-XX-XX　基线版本：`COMBATMAP_VERSION = 'v0.93'`

---

## 0. 结论（TL;DR）

combatmap 的**功能已相当完整**（动态战雾 / 墙体 LOS / 多场景 / 单位库 / 先攻条 / P2P / 云端持久化 / 底图对齐 / 测量都已落地），
但**界面信息架构没有跟上**：它把「高频操作用的核心工具」「低频管理操作」「DM 专属操作」全部**平铺**在一个 290px 的固定左栏里，
导致：

1. **地图空间被左栏吃掉** → 画布是配角，而不是主角；
2. **信息密度失衡** → 13 个工具按钮 + 32 个地形色块挤在一列，找不到要用的；
3. **坐标太抢眼** → 默认每格画 `q,r`，整张图像电子表格；
4. **缺「玩家名册」** → 枭熊左上角常驻的「球员」面板，在我们这藏在「房间」页签里；
5. **无视觉层级** → 低频/DM 操作与核心工具同权重。

**改造方向**：对齐枭熊的「**地图是主角，工具是配角**」信息架构——核心工具收进一条可折叠的窄停靠栏，
复杂选项按需**弹出**，低频/DM 操作**降权**，玩家名册**常驻可折叠**，坐标**默认低调**。

> ⚠️ **一个需要你拍板的取舍**：combatmap 目前主打「✏️ 手绘质感」的暖色牛皮纸风（`body.art-handdrawn`），
> 而枭熊是**干净暗色调**。这套改造只动**布局/信息架构**，**不换视觉风格**；是否要顺带对齐枭熊的暗色简洁风，
> 见 §6，需要你确认后再做。

## 1. 设计目标与原则

面向「轻量地图桌」（对齐枭熊，不追 FVTT 全功能），确立 5 条信息架构原则：

| # | 原则 | 说明 |
|---|---|---|
| 1 | **地图是主角** | 默认视图画布占满，任何工具/面板不常驻挤压地图 |
| 2 | **高频可见，低频收起来** | 核心工具默认可见；复杂设置/导出/场景等按需弹出或降权 |
| 3 | **DM 与玩家分层** | DM 专属操作（战雾/DM层/先攻/导入/对齐）与玩家可见工具**视觉区分**并在玩家视图隐藏 |
| 4 | **选择即上下文** | 选中某工具后，相关选项就近弹出（如笔刷→地形选择器），用完收起 |
| 5 | **少即是多** | 一次尽量只呈现「当前这一步」用得上的东西，减少扫读 |

## 2. 现状 UI 结构盘点

### 2.1 左工具栏 `#toolbar`（fixed 290px，`index.html:12-19,167-329`）

结构自上而下：

```
⚔️ 战斗地图 v0.93            ← 标题 + 版本号
🎲 DM 视图 / 👁️ 玩家视图      ← 角色切换
[页签] 工具/单位库/地图/数据/房间/显示   ← 6 个页签
  ├ 工具页: 13 个 tool-btn + 地形色板(32+) + 操作提示
  ├ 单位库页: 新建/存选中 + 预设卡片网格
  ├ 地图页: 导入底图/数值/网格对齐 + 模板一键生成
  ├ 数据页: 场景 / 云端 / 保存分享 / 撤销重做 / 导出
  ├ 房间页: 在线房间 / 行动顺序 / 编组
  └ 显示页: 网格/坐标/DM层/战雾/动态视野/手绘 开关
页脚: 版本 + 操作提示（滚轮缩放/拖拽平移/右键菜单…）
```

**现状问题**：

- **宽度 290px 常驻**，画布被永久压缩（`@media (max-width:800px)` 才收窄到 48px，但多数桌面窗口 >800px）。
- **工具页信息密度最高**：13 个工具按钮 + 32 个地形色块 + 提示，是整屏最重的一块。
- **6 个页签是「任务型」分区**，但里面塞了太多**低频/一次性**操作（云端、导出、底图对齐、场景复制），
  这些本不该常驻在「主操作」层级。
- **玩家视图只是禁用按钮 + 顶上一行提示横幅**（`#player-banner`），没有真正把玩家视角当成「另一种界面」。

### 2.2 地形色板 `#terrain-palette`（`index.html:219-222`，`ui.js:121-151`）

`rebuildTerrainPalette()` 把 `getTerrainList()` 的**全部地形**（内置 13 + 扩展 19 + 自定义）渲染成彩色方块：

- 每块 = `<button class="tool-btn" data-terrain>`，背景色 + emoji + 名称；
- **共 32+ 个**，无分类、无最近使用、无搜索，像一副调色板。

**现状问题**：常见地形（地面/墙/困难/水域）和冷门地形（王座/神殿/祭坛/田地）**同权重**堆在一起；
要找到目标得整屏扫读，`paint` 工具的高频路径被拖慢。

### 2.3 画布上的悬浮元素（`#canvas-container`，`index.html:331-354`）

| 元素 | 位置 | 问题 |
|---|---|---|
| `#coord-indicator` | 左上 | 显示当前工具名，功能 OK，但与工具提示重复 |
| `#zoom-indicator` | 右上 | 缩放百分比，OK |
| `#info-panel` | 底部 | 选中格信息（坐标/地形/标签/边界），OK 但**常驻占位** |
| `#empty-hint` | 居中 | 空态引导卡，OK |
| `#bg-align-bar` | 顶部 | 对齐模式状态条，OK（仅对齐时显示） |

### 2.4 坐标渲染（`render.js:725-730`）

```js
if (showCoords) {
  ctx.font = `${Math.max(8, CELL_SIZE*0.18)}px monospace`;
  ctx.fillText(`${q},${r}`, p.x, p.y + CELL_SIZE*0.30);  // 每个格子都画
}
```

`showCoords` **默认开着**（`index.html:308` `#chk-coords checked`），意味着**每格**都标 `q,r`。
这就是截图里「整张图像电子表格」的直接来源。

### 2.5 弹窗（12+ 个 modal）

`room / corridor / cave / open / zone / label / shape / line / unit / terrain / map-settings / initiative / group / dm / share / online`。

弹窗本身结构正常，但**入口层级**上「模板生成」「导出」「云端」「场景」混在核心操作区，属于信息架构问题而非弹窗问题。

## 3. 与枭熊 / FVTT 的对照

| 维度 | 枭熊 | FVTT | combatmap v0.93 | 优先级 |
|---|---|---|---|---|
| 地图空间 | 工具栏窄竖条 + 悬浮面板，地图占满 | 场景为主，工具浮层 | ⚠️ 固定 290px 左栏 | **高** |
| 工具入口 | 默认露几个核心图标，其余收扩展 | 侧栏可折叠 | ⚠️ 13 个平铺 | **高** |
| 地形选择 | 按需选，无常驻列表 | 侧栏分类 | ⚠️ 32+ 色块常驻 | **高** |
| 坐标 | 默认低调，测量时出现 | 场景可配 | ⚠️ 默认每格标注 | 中 |
| 玩家名册 | 左上角常驻「球员」面板 | 侧栏参与列表 | ❌ 藏在「房间」页签 | **高** |
| 低频操作 | 收进左上角菜单/设置 | 场景配置 | ⚠️ 全堆 6 页签 | 中 |
| 视觉风格 | 干净暗色调 | 可主题 | 🟡 手绘牛皮纸（卖点） | 待定 |

**一句话**：功能已是「轻量地图桌」，但**界面还停留在「画图工具」**——把画图工具的所有按钮一次性摊给用户。

## 4. 具体改造项（按区域）

> 每条给出「现状 → 目标」，并标注改动面（HTML / CSS / JS）。**都只动源码，不动 `combatmap.dist.html` 产物。**

### A. 左工具栏 → 可折叠窄停靠栏（改动面：CSS 为主 + 少量 JS）

- **现状**：`#toolbar` 固定 290px，常驻。
- **目标**：默认收成一条**窄竖条（约 64–72px）**，只显示核心工具图标；点击图标或面板把手才展开工具面板。
  - 顶部：⚔️ 图标（可折叠按钮）。
  - 窄态：只露「选择/笔刷/单位/测量/战雾」等高频图标（带 `title` 工具提示）。
  - 展开态：完整工具 + 地形选择器 + 单位库等（可拖 / 可折叠）。
- **实现**：为 `#toolbar` 加 `.collapsed` 类切换；窄态隐藏文字 label、页签标签、低频区块；用 CSS `transition: width` 平滑。
- **收益**：地图空间最大化，是与枭熊对齐的**最关键一步**。

### B. 地形选择 → 弹出式选择器（改动面：HTML + ui.js）

- **现状**：32+ 色块常驻 `#terrain-palette`。
- **目标**：选「笔刷」工具后，地形选择器**就近弹出**（浮动在笔刷按钮旁或画布上），用后收起；不常驻。
  - 增加**分类**：`常用`（地面/墙/困难/水域/掩体/火/酸/尖刺…）+ `更多`（祭坛/王座/传送/田地…）+ `最近使用`（记录最近 N 个）。
  - 保留「⚙️ 管理」入口（自定义地形）。
- **实现**：把 `#terrain-palette` 改为浮动容器（`position:absolute`，默认 `display:none`），`setTool('paint')` 时展开；按 `terrain.category` 分组，`EXTRA_TERRAIN` 默认折叠进「更多」。
- **收益**：画地形的高频路径从「扫一屏」变成「点开即得常用项」。

### C. 坐标 → 默认低调（改动面：index.html + render.js 可选）

- **现状**：`showCoords` 默认开，每格标 `q,r`。
- **目标**：**默认关闭**，改为「测量/对齐时临时显示」或「仅在需要时手动勾选」。
  - 最小改法：`index.html:308` 的 `#chk-coords` 去掉 `checked`。
  - 进阶改法：`render.js` 把每格标注改为**仅边缘轴标**（顶部列号 + 左侧行号），像枭熊的测量态；或在 `showCoords` 下同时显示但降透明度/缩小字号。
- **收益**：消除「电子表格感」，突出地图内容。

### D. 新增常驻可折叠玩家名册（改动面：HTML + JS）

- **现状**：无；在线房间信息藏在「房间」页签 `#page-room`。
- **目标**：左上角（画布上）新增**可折叠的「玩家」面板**，与枭熊「球员」对齐：
  - 列出当前**在线房间成员**：头像/名字/角色（DM/玩家）状态。
  - 未开在线房间时显示「离线」或隐藏该面板。
  - 玩家视图下也可见（告诉玩家「谁在局里」）。
- **实现**：复用 `online.js` 的连接状态与成员列表；新增 DOM 容器 + `online` 事件刷新。这需要你确认是否纳入本次（见 §8）。
- **收益**：跑团时的「存在感」，枭熊核心体验之一。

### E. 高频 / 低频 / DM 分层（改动面：HTML 为主）

把现有操作按频率与角色重新归组，**降低低频项的可见性**：

- **高频（默认可及）**：选择 / 笔刷 / 单位 / 测量 / 战雾 / 撤销重做。
- **中频（半可见）**：墙壁 / 门 / 标签 / 区域 / 线段 / 图片。
- **低频 / 管理（收进二级或弹窗）**：导入底图 / 网格对齐 / 场景 / 云端 / 导出 / 模板生成 / 编组 / 地形管理。
- **DM 专属（视觉区分 + 玩家视图隐藏）**：DM层 / 战雾 / 行动顺序 / 导入底图 / 网格对齐；用「🎲 DM」徽标 + 独立分区，玩家视图整块禁用/隐藏。
- 参考枭熊：底部「设置/菜单」收拢所有低频项。

### F. 顶栏 / 页脚 / 帮助

- 页脚目前的版本 + 操作提示适合保留，但可改为「?」帮助入口（快捷键速查），不再占底部常驻。
- 顶栏可考虑加一个**全局菜单（☰）**收拢「新建/保存/云端/导出/分享/设置」，与枭熊的左上角菜单对齐。

## 5. 信息架构重排（目标结构）

改造后的左栏（折叠态 / 展开态）目标：

```
[折叠态 - 窄竖条 64px]           [展开态 - 弹出面板 ~300px]
┌─────┐                        ┌──────────────────────────────┐
│ ⚔️  │ ← 折叠/展开             │ 顶部：工具标题 + 折叠把手       │
│ 👆  │ ← 选择                  │ 分区1：核心工具（高频图标+名）  │
│ 🖌️  │ ← 笔刷 → 弹出地形选择器  │ 分区2：绘图/标注工具（中频）    │
│ 🧝  │ ← 单位                  │ 分区3：DM 专属（🎲 徽标）      │
│ 📐  │ ← 测量                  │ ──────────────                │
│ 🌫️  │ ← 战雾(DM)              │ 玩家名册（可折叠，常驻）        │
│ ☰   │ ← 更多 → 弹出全部/设置   │ ──────────────                │
└─────┘                        │ ☰ 菜单：场景/云端/导出/设置    │
                               └──────────────────────────────┘
```

**画布**：坐标默认关闭；左上角常驻可折叠玩家名册；右下角缩放指示；底部选中格信息（可点击收起）。

## 6. 视觉风格（需你确认）

- combatmap 目前 `body.art-handdrawn` 是**手绘牛皮纸暖色调**（`index.html:152-161`），且有「✏️ 手绘质感」开关（`#chk-art-style`）。
- 枭熊是**干净暗色**（深灰蓝底 + 白色高亮 + 极简）。
- **本方案只重排布局与信息层级，不改视觉风格**（手绘质感是差异化卖点，且已可切换）。
- 若你希望**顺带向枭熊暗色靠拢**（更素、更聚焦），可作为**独立的一个后续版本**，与布局改造分开，方便回滚与验收。
- **建议**：先只做布局/信息架构（v0.94），视觉风格单独评估（v0.95+ 可选）。

## 7. 分阶段落地路线（每阶段独立可上线）

> 遵循项目约定：**小步递增版本号**（当前 v0.93 → v0.94 → …），**不动产物**，每次落地同步 `COMBATMAP_VERSION` / `index.html` 标题页脚 / `CHANGELOG.md`。

### 阶段 1（v0.94）— 低风险、快速见效
- C. 坐标**默认关闭**（`index.html` 去掉 `checked`，改 `render.js` 为「仅边缘轴标」+ 测量时临时显示）。
- E. 工具**归组分层**：`#toolbar` 内按「核心 / 绘图标注 / DM专属」分成视觉区块；DM 专属加「🎲 DM」徽标 + 玩家视图隐藏整块。
- B. 地形色板**收成单选 + 分类**：默认只展示「常用」地形，其余收进「更多」折叠；保留「最近使用」。
- **回归**：确认 `paint` 流程、玩家视图、键盘快捷键不受影响；跑 `build.js` 校验语法。

### 阶段 2（v0.95）— 布局重构（改动最大）
- A. 左工具栏 → **可折叠窄停靠栏**（`#toolbar.collapsed`，窄态 64px 只露高频图标；CSS transition）。
- 新增 **☰ 全局菜单**收拢低频项（场景/云端/导出/分享/设置）。
- **回归重点**：窄态与展开态切换、6 页签在窄态下的可达性、`@media (max-width:800px)` 兼容、触屏。

### 阶段 3（v0.96）— 玩家名册 + 体验收尾
- D. 新增**常驻可折叠玩家名册**（复用 `online.js` 成员状态）。
- F. 帮助入口（快捷键速查面板）。
- **回归重点**：在线房间成员刷新、玩家视图下名册可见性、P2P 连接状态展示。

### 阶段 4（可选，v0.97+）— 视觉风格向枭熊靠拢（需确认）
- 若决定做，单独评估暗色主题，与手绘质感并存（可切换），不合并进阶段 1-3。

## 8. 风险与回归清单

| 风险 | 影响 | 规避 |
|---|---|---|
| 改动面大，误触产物 | `combatmap.dist.html` 被手改 → 与源码不一致 | **只改 `2_工具/combatmap/` 源码**，发布才 `node build.js` |
| 布局重构破坏触屏 / 窄屏 | 窄态下页签不可达 | 保留 `@media (max-width:800px)`，窄态提供「全部」入口 |
| 玩家名册依赖在线状态 | 未开在线房间面板空转 | 未连接时显示「离线」或隐藏面板 |
| 坐标默认关闭影响老用户 | 习惯看坐标的用户找不到 | 保留显式勾选开关，CHANGELOG 说明 |
| 手绘质感是卖点 | 若误改风格引发不满 | 阶段 1-3 **不动视觉**，风格单独评估 |
| 在线同步 / 撤销 / 分享 | 布局改动不应影响数据 | 所有改动**只碰渲染与 DOM 结构**，不改数据流（`combatData/fog/tokens/shapes…`） |
