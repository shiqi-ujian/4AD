# CHANGELOG

## [v0.8] — 开发中 (Unreleased)

### 重构
- **🎯 网格对齐系统重做（修复"导入底图画格子对不上"）**：
  - 重写三点求解数学：参考点改用**图像像素坐标系**换算（基于开始对齐时的底图映射快照），修正旧算法中"工具格/画布像素/图像像素混算"的根本性错误。
  - 引导式操作：第 1 点 = 底图格线交点（基准），第 2 点 = 同水平线向右 N 格交点，第 3 点 = 向下 N 格交点；支持 2 点粗略对齐（按正方形格子）。
  - 对齐条新增「点间格数」输入（默认 1），**实时重算**并叠加**对齐网格预览**（≥2 点时直接看到预期网格贴合效果），再点「✓ 完成」生效。
  - 对齐模式下底图以全不透明度显示，参考点十字线修正为与世界坐标一致。
- **🧺 单位库（token 管理终于有家了）**：新增 `js/tokenlib.js` 模块。
  - 可复用单位预设（名称/类型/图标/底色/HP/AC/速度/状态/头像/尺寸）保存到 localStorage；首装自带 6 个示例。
  - 面板网格展示预设卡片（类型角标 + 圆形头像 + 悬停编辑/删除）；「➕ 新建预设」「📥 存选中单位」。
  - 单位弹窗新增「单位库模式」：新建/编辑预设直接入库存档，不强制上地图。
  - 右键地图单位 →「📥 存入单位库」；单位库随保存 JSON / 分享链接 / 在线同步传递。
- **🧝 单位摆放流程重构（修复"摆放一次卡一辈子"）**：
  - 点击单位按钮 = 打开单位库；点击预设 = "拿起" → 地图上点击放置。
  - **放置后自动回到「选择」工具**（可直接拖动/右键），按住 **Shift 可连续摆放**，Esc 取消。
  - 切换工具时自动清理"未放置"状态，不再残留 pending 导致下次进入卡死。

### 新增
- **🎲 DM / 玩家视图切换**：面板顶部一键切换；玩家视图下禁用 DM 层 / 战雾绘制 / 行动顺序 / 导入底图 / 网格对齐，DM 层强制关闭；在线加入房间自动进入玩家视图，离开恢复 DM。
- **🗂️ 左侧工具栏重组为可折叠分区**：工具 / 单位库 / 地形 / 地图(DM) / 数据 / 房间 / 显示 七个分区；DM 专属项带 🕵️ 徽标与紫色描边；地形调色板改为紧凑图标网格（33 种不再刷屏）。
- **🖼️ 导入底图流程优化**：导入后不再强制弹设置窗/进入对齐模式；无底图时「🎯 网格对齐」按钮禁用并提示先导入；画布空态显示引导卡片（导入底图 / 直接画 / 模板生成，可"知道了"关闭）。
- **美术优化**：单位 token 增加类型色环（玩家绿/敌人红/NPC蓝/盟友金）、投影、圆角名牌与描边、带边框血条（绿/黄/红按血量变色）；底图对齐网格预览。

### 修复
- 底图移除时同步退出对齐模式。
- dev 多文件模式（index.html 直接打开）下导出/保存按钮绑定改为懒调用，与 dist 行为一致。

## [v0.7] — 开发中 (Unreleased)

### 新增
- **单位属性深化（🧝 单位）**：
  - 单位新增 **AC / 速度 / 临时 HP / 备注** 字段；画布上显示 AC 右下角徽标、速度左下角徽标、临时 HP 蓝色副血条。
  - 单位支持上传**圆形象头像图片**（可选，圆形裁剪显示）。
  - 支持**自定义状态**：在单位弹窗里添加「名称 + 图标」，随保存 JSON / 分享 / 在线同步传递。
- **右键战斗快捷操作**：
  - 右键单位可直接 **受伤 -1 / -5 / 自定义、治疗 +1 / +5 / 自定义、设置 HP**。
  - 扣血时**先消耗临时 HP**，超出部分才扣本体；治疗时先回满 HP，溢出转为临时 HP。
- **先攻条双向联动（🧭 行动顺序）**：
  - 从单位导入的先攻条目记录 `tokenId`；右键扣血/治疗会自动同步到先攻条，先攻条里改 HP 也会回写地图单位。
  - 删除单位时自动清理对应先攻条目与编组成员。
- **多选 / 复制 / 编组**：
  - **Shift/Ctrl 点选**单位可多选，画布显示黄色主轴 + 蓝色多选框；Esc 清空。
  - **Ctrl/Cmd+D 复制**选中单位（副本偏移半格，不自动进先攻条）；Delete 批量删除。
  - **🧩 编组**：多选单位后创建编组，拖动组内任一成员整组移动；编组列表可查看/删除。
- 保存 JSON / 紧凑分享 / 在线同步全部接入 `groups`、`customUnitStatuses`、单位新字段；自定义状态写入 localStorage。
- 版本号提升 v0.7（`COMBATMAP_VERSION`），UI/页脚同步展示。

## [v0.6] — 开发中 (Unreleased)

### 新增
- **底图快速对齐（🎯 网格对齐）**：
  - 专门适配“图片自带格线”的地图：进入对齐模式后，在画布上点击 3 个格线交点（第 1 个基准点、第 2 个向右、第 3 个向下），系统自动算出底图比例与偏移，立刻贴合网格。
  - 对齐模式下可拖底图四角手柄调整大小、整体拖动微调。
  - 顶部弹出「✓ 完成 / ✕ 取消」操作条：点完参考点后不再自动应用，由你确认完成；按「完成」才写入对齐结果，避免误触。
  - 数值弹窗仍保留给需要精确微调的场景。
- **导入图片底图（🖼️ 导入底图）**：
  - 选择本地图片作为战斗地图底图，自动按原始像素估算格子尺寸，下方叠加当前战斗网格。
  - 「⚙️ 底图」弹窗可调整：左上角坐标（格）、宽度/高度（格数）、不透明度，修改时实时预览，适合对已有地图的网格进行对齐。
  - 底图随保存 JSON / 分享链接 / 在线同步一起传递；导出 PNG 也包含底图。
  - 玩家端在线视角仍不会收到 DM 层/战雾；底图属于玩家可见地图内容。
- **在线房间角色与隐私过滤（🌐 在线）**：
  - 创建房间 = DM（可编辑全部内容）；加入房间 = 玩家（只接收玩家可见地图）。
  - 主机向玩家下发的快照自动剥离 `dmData`（DM 层）、`fog`（战雾）、`initiativeOrder/Index`（行动顺序）。
  - 玩家端禁用 DM 层 / 战雾 / 行动顺序入口，状态栏显示「DM / 玩家」。
  - 玩家加入时声明 `role=player`；严格权限仍需后续加服务端/信令签发，当前为 P2P 角色约定。
- **DM 隐藏层（🕵️ DM层 Y）**：GM 可在格子上添加隐藏标记/说明（图标 + 文字），仅在本机「显示 DM 层」开启时渲染；保存 JSON / 分享链接 / 在线同步均已携带数据，导出 PNG 默认不透出 DM 层。
  - 新增 `js/state.js` 的 `dmData` 数据层，支持拖入 / 双击 / 右键编辑。
- **战雾 / 迷雾（🌫️ 战雾 F）**：逐格遮罩 + 揭示，支持拖拽连续涂雾；默认开启显示战雾，Alt 按住切揭示。
  - 擦除工具新增「仅 DM 层」「仅战雾」模式，右键菜单可快速切换单格。
- **行动顺序 / 先攻条（🧭 行动顺序）**：独立弹窗管理轮次，可手动添加、从单位一键导入、上移 / 下移 / 删除、编辑 HP、上一轮 / 下一轮。
- 工具栏增加「显示 DM 层 / 显示战雾」开关；新增快捷键 `Y` / `F`。
- 撤销/重做、保存 / 加载、紧凑分享、在线同步全部接入以上新数据。
