## [v0.100] — 移动端适配（底部抽屉工具栏）& 画布撑满修复

### 🐛 修复：画布在某些窗口下「只画一半/黑边/工具栏消失」
- **现象**：特定窗口宽度下，地图网格只占左侧一块，右侧大片黑色，工具栏也像消失了一样。
- **根因**：画布尺寸只在 `window.resize` 时更新，而容器宽度会随「工具栏折叠/展开」「移动端断点翻转」变化；容器变宽后画布仍停留在旧的窄尺寸（默认 300×150），于是网格只画在那一小块、其余露黑。
- **修复**：
  - 给 `canvas` 加 `width:100%;height:100%`，画布元素永远撑满容器；
  - 用 `ResizeObserver` 监听 `#canvas-container`，容器尺寸一变就 `resizeCanvas()` 重填，不再漏黑边。
  - 桌面端（>820px）完整左侧工具栏、手机端（<820px）底部抽屉布局均验证正常。

### 移动端（<820px）：左栏改「底部抽屉」
- **问题**：此前工具栏是左侧固定栏，手机窄屏下被压成一条 ~48px 图标缝，既白白占用地图宽度，又把控件挤成一列难用。
- **改动**：移动端下 `#app` 改为上下排布，画布铺满屏幕；工具栏移到**屏幕底部**。
  - **默认收起**为底部一条横向滚动的核心工具图标条（✅ 最大化地图）。
  - 点把手（▲/▼）向上弹出**完整工具栏抽屉**（工具 / 单位库 / 地图 / 数据 / 房间 / 显示 等全部面板可见可滚动）。
- **功能**：底部图标条内核工具（选择/笔刷/移动/测量）可直接点选切换，横向可滑动；收起态不占地图高度。
- **桌面端（>820px）不变**：仍为左侧完整工具栏，原有折叠/展开按钮、全部面板与缩略布局不受影响。

## [v0.99] — 开发中 (Unreleased)

### 重构（在线房间：改「服务器权威 (server-authoritative)」）
- **服务器成为房间唯一权威**：由 chm-web 的 `/ws` 中继持有并应用权威地图状态；不再依赖 DM 反复广播整图快照。
  - DM 通过 `sync` 发布/更新权威全量；一切实时改动（token / 玩家绘制 / 迷雾）走**增量**，服务器校验权限后应用到自己的状态再广播。
  - **新加入/重连成员由服务器下发权威状态**，不依赖 DM 正在广播；DM 刷新后房间不散、状态从服务器恢复。
  - **权限由服务器用「发送者成员 id」校验**（不是靠客户端自报 owner）：玩家只能改自己拥有的 token、只能增删改自己画的 shape/line；地形/迷雾/DM层仅 DM。玩家伪造 owner 会被拒。
- **客户端改服务器权威**：接收 `model`/`settings`；人人发增量（DM 的 token/绘制也走增量）；**DM 内容变更才发布权威 sync**（拖镜头/改选中不触发）；合并保护：远端同步不再重置**本地视角/token库/自己的绘制/选中/撤销**。
- **迷雾同步**：DM 画/揭示战雾 → 批量 `fogEdit` 增量（遮蔽=1、揭示=删除），实时且不靠整图；玩家端能看到已揭示区域。
- 修复/体验：移除「点弹窗外部即退出」；记忆房间+身份，刷新后自动回房。
- 版本号 v0.99：COMBATMAP_VERSION / 标题 / 页脚 / 日志同步更新。

## [v0.98] — 开发中 (Unreleased)

### 重构（在线房间：PeerJS P2P → WebSocket 服务器中继 hub）
- **在线功能改为服务器中继**：不再用公共 PeerJS（`0.peerjs.com`）信令 + P2P 点对点。改为成员各自连 `chm-web` 的 WebSocket `/ws`，服务器做房间成员管理 + 消息广播。跨运营商/跨网络稳定，不再依赖公共信令，也不用开 TURN/NAT 端口（走 443/WSS）。
- **修复「两端人数不一致」**：成员名单改由服务器统一广播，主机/玩家都按同一份 `roster` 渲染，不再出现「电脑=1 人、平板=2 人」的半开连接分裂。
- **修复「刷新后房间连不回」**：服务器缓存 DM 权威快照，DM/玩家刷新或断线后**自动重连并补发快照**；房间不因某一成员刷新而散（成员在房间就在，DM 回来恢复）。
- **心跳保活**：客户端每 5s 发 ping，15s 无 pong 判定失联→自动重连（带指数退避）。
- **DM 权威、玩家只读**：只有 DM 端广播权威完整快照（含 DM 层/战雾/行动顺序），玩家端按角色过滤只收「玩家可见地图」，避免玩家快照覆盖 DM 隐藏层。
- **配置**：WebSocket 地址默认取页面同源 `/ws`，可用 `localStorage.combatmap_ws_url` 覆盖（如 `wss://map.chmweb.cn/ws`）。
- 移除 PeerJS CDN 依赖与相关降级提示；`js/state.js` 的 `viewRoleIsPlayer` 判定改用 `onlineWS`。

- **底图解锁后一步拖动**：底图未锁定时，在「选择」工具下**点住底图直接拖拽即移动**（无需先点选再拖）；锁定仍防误拖。

  - 专门适配“图片自带格线”的地图：进入对齐模式后，在画布上点击 3 个格线交点（第 1 个基准点、第 2 个向右、第 3 个向下），系统自动算出底图比例与偏移，立刻贴合网格。
  - 对齐模式下可拖底图四角手柄调整大小、整体拖动微调。
  - 顶部弹出「✓ 完成 / ✕ 取消」操作条：点完参考点后不再自动应用，由你确认完成；按「完成」才写入对齐结果，避免误触。
  - 数值弹窗仍保留给需要精确微调的场景。
- **导入图片底图（🖼️ 导入底图）**：
  - 选择本地图片作为战斗地图底图，自动按原始像素估算格子尺寸，下方叠加当前战斗网格。
  - 「⚙️ 底图」弹窗可调整：左上角坐标（格）、宽度/高度（格数）、不透明度，修改时实时预览，适合对已有地图的网格进行对齐。
  - 底图随保存 JSON / 分享链接 / 在线同步一起传递；导出 PNG 也包含底图。
  - 玩家端在线视角仍不会收到 DM 层/战雾；底图属于玩家可见地图内容。
- **在线房间角色与隐私过滤（🌐 在线）**：
  - 创建房间 = DM（可编辑全部内容）；加入房间 = 玩家（只接收玩家可见地图）。
  - 主机向玩家下发的快照自动剥离 `dmData`（DM 层）、`fog`（战雾）、`initiativeOrder/Index`（行动顺序）。
  - 玩家端禁用 DM 层 / 战雾 / 行动顺序入口，状态栏显示「DM / 玩家」。
  - 玩家加入时声明 `role=player`；严格权限仍需后续加服务端/信令签发，当前为 P2P 角色约定。
- **DM 隐藏层（🕵️ DM层 Y）**：GM 可在格子上添加隐藏标记/说明（图标 + 文字），仅在本机「显示 DM 层」开启时渲染；保存 JSON / 分享链接 / 在线同步均已携带数据，导出 PNG 默认不透出 DM 层。
  - 新增 `js/state.js` 的 `dmData` 数据层，支持拖入 / 双击 / 右键编辑。
- **战雾 / 迷雾（🌫️ 战雾 F）**：逐格遮罩 + 揭示，支持拖拽连续涂雾；默认开启显示战雾，Alt 按住切揭示。
  - 擦除工具新增「仅 DM 层」「仅战雾」模式，右键菜单可快速切换单格。
- **行动顺序 / 先攻条（🧭 行动顺序）**：独立弹窗管理轮次，可手动添加、从单位一键导入、上移 / 下移 / 删除、编辑 HP、上一轮 / 下一轮。
- 工具栏增加「显示 DM 层 / 显示战雾」开关；新增快捷键 `Y` / `F`。
- 撤销/重做、保存 / 加载、紧凑分享、在线同步全部接入以上新数据。
